## 内容纪律

- **无源不写**：所有数字必须来自来源清单中的公开来源，凭知识推断的一律不写。
- **冲突并列**：同一指标在不同文献给出不同数值时（如洛川剖面 130 m / 135 m、巴丹吉林面积 4.7 万 / 4.92 万 km²），并列呈现，不取平均、不换算、不择一。
- **争议不裁决**：如庐山冰川之争，只陈述双方论据与出处。
