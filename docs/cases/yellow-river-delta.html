总览 · 实例 · 海岸与河口

黄河三角洲

来沙一断，海岸线立刻改口

海岸与河口第十一章　海岸地貌及其堆积物由快速淤进转为冲淤交替，部分叶瓣持续蚀退

全世界造陆最快的地方之一，也是最直观的"泥沙账本"：来沙多就进，来沙少就退。1976 年改道、1996 年出汊、2002 年小浪底调水调沙，每一次人类干预都写在海岸线上。

现场能看到什么

  • 看河口的分汊与沙嘴：现行流路的沙嘴在向海推进，废弃流路的叶瓣在往回退，同一三角洲上两种方向并存。
  • 看滩面的淤泥质特征：黄河口以细颗粒淤泥为主，潮滩宽阔，与砂质海岸的陡剖面完全不同。
  • 看人工海堤段：1990 年代后东营港至孤东油田因海堤防护，岸线基本锁死 —— 这是"人类活动成为地貌营力"的直接证据。
  • 看湿地植被带：从水边到内陆依次为光滩、盐地碱蓬、芦苇等，反映的是淹没频率与盐度的梯度。

背后的原理

  1. 三角洲的两股力量：河流供沙使岸线向海推进，海洋动力（波浪、潮流）侵蚀使岸线向陆后退。谁占上风，取决于来沙量与海洋能量的比值。
  2. 为什么黄河三角洲造陆快：含沙量极高（水少沙多），河口淤积延伸速率可达 2—3 km/a，导致尾闾河道周期性出汊摆动。
  3. 改道的机制：河道淤高 → 比降变缓 → 泄流不畅 → 寻找新的、更短更陡的入海路径。1946 年前改道 7 次，之后又有 1953、1964、1976、1996、2007 等多次人工或自然改道。
  4. 为什么 1989 年后转蚀退：输沙量断崖式下跌（小浪底水库、调水调沙、退耕还林、工农业用水），海洋动力未变而物源锐减，抗侵蚀能力崩溃。
  5. 极端事件的放大效应：低物源时期，一次风暴潮的蚀退量（−1243 m/a）可达平均速率（−146 m/a）的 8 倍以上 —— 风险评估不能只看年均值。
  6. "每亿吨沙能换来多少岸线"：不同流路时期分别为 0.21—0.23、0.31、1.16 km/亿 t，海域越浅、海洋动力越弱，单位泥沙的造陆效率越高。

这些数字在说什么

造陆速率是"流量账"年均 40.8 km² → 22.1 km² 的下降，本质是来沙从 142.8 亿 t 降到 124.17 亿 t 再降到 10.34 亿 t
同一三角洲的两种命运现行河口在淤、废弃叶瓣在蚀，说明三角洲不是整体进退，而是"沉积中心"在迁移
1.76 亿 t/a 的临界值这是把"冲淤平衡"量化成管理指标的尝试：低于它，三角洲净蚀退
人类已是主要营力改道、水库、调水调沙、海堤、生态补水，每一项的量级都超过了自然波动 —— 现代地貌学必须把人算进去
