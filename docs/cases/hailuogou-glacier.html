海螺沟冰川

一条正在快速后退的海洋型冰川

冰川第八章　冰川地貌与冰川堆积物持续退缩中，近两年显著加速

冰川末端伸进针叶林里，落差 3900 米，大冰瀑布垂直 1080 米。它同时是"海洋型冰川"的教科书样本：对气候变化的响应快得肉眼可见。

现场能看到什么

  • 看冰舌表面的表碛：海螺沟冰舌大部被碎屑覆盖，远看是灰的、脏的，不是你在画册上看到的白冰。
  • 找终碛和侧碛：冰川末端外围最新鲜的那几道垄，就是它刚刚退到过的位置。
  • 看冰面湖、冰裂隙、冰洞、冰塔 —— 这些都是"正在强烈消融"的证据，不是静态景观。
  • 沿退缩区往回走：从裸露冰碛 → 草本 → 小树 → 冬瓜杨 → 峨眉冷杉，2 公里内走完一百年的演替。

背后的原理

  1. 成冰：积累区在高海拔，雪 → 粒雪 → 冰川冰；贡嘎山积累区雪崩频繁，雪崩补给占雪线以上总补给的约 44%。
  2. 流动：冰在重力下塑性流动，速度可达百米级每年（冰川中部 3950 m 处中流线约 171 m/a）。
  3. 消融：海洋型冰川温度接近压力融点，冰床普遍存在压融水，水膜增厚促进底部滑动，因此对升温极其敏感。
  4. 为什么海螺沟退得比大陆型冰川快：海洋型冰川温度高、降水多、响应快；同样升温下，它的末端后退幅度远大于唐古拉山那类低温大陆型冰川。
  5. 反馈：退缩后裸露的冰碛在暖湿条件下很快被先锋植物定殖，演替序列清晰：5 年草本 → 10 年小树 → 20 年冬瓜杨中树 → 40 年大树 → 60 年峨眉冷杉中龄林 → 100 年冷杉林。

这些数字在说什么

表碛的双面作用薄表碛加速消融（反照率低），厚表碛反而隔热保护冰体 —— 所以"脏"的冰川不一定退得更快
退缩速率的口径1966—2009 的 25—30 m/a 与 1990—2020 的 12.33 m/a 时段不同，不能简单说"变慢了"，要看原始定义的起止年
冰瀑布1080 m 的落差意味着冰川在此处于极度拉伸流动状态，冰崩、雪崩终年频发
去现场的意义这里是"把第八章冰川侵蚀/堆积地貌一次看全"的地方：U 形谷、冰碛、冰水堆积、冰蚀地貌同框

争议与口径

长度、面积、末端海拔在不同来源各有两三个数值（13.1/12.9 km、25.71/24.27 km²、2990/2900/2940 m），可能源于测年不同与统计边界定义不同。本站并列。

位置

四川省甘孜州泸定县，贡嘎山东坡

可达性

海螺沟景区（国家 5A），有公路直达冰川观景台与城门洞，是同纬度最容易到达的现代冰川之一。

状态
