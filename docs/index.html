《地貌学及第四纪地质学》按学科体系写成：先基本问题，后分论各营力，再讲中国第四纪与研究方法。 这套结构适合上课，不适合"我要去看"。本站把它重构为三层：营力原理（为什么会这样）→ 现存实例（去哪里看、看什么数字）→ 野外判定（怎么认、怎么防认错）。 每个实例都给出可核对的实测数据与出处，冲突数据并列不合并。

营力 × 实例

营力系统原书章节控制变量实例
风化与残积第四章　残积物及风化壳岩石在原地被改造。控制变量是：气候（温度+降水）、岩性、地形排水、时间。宣城网纹红土
斜坡与重力第五章　斜坡地貌与斜坡堆积物一切"往下掉"的过程：崩塌、撒落、滑坡、土层流动。控制变量是坡度、岩土强度、水。新滩滑坡与链子崖
流水第六章　流水地貌及其堆积物暂时性流水（洪流）与常年性河流。控制变量是流量、比降、含沙量、基面。永定河冲洪积扇
岩溶第七章　岩溶地貌及岩溶堆积物水对可溶岩的化学溶蚀。控制变量是岩性纯度与厚度、水的溶蚀力、透水性、流动性。桂林峰林与峰丛
冰川第八章　冰川地貌与冰川堆积物冰的积累、流动与消融。控制变量是积累区面积、气温（平衡线高度）、地形。海螺沟冰川、庐山"冰川"之争
冻土与冰缘第九章　冻土地貌冻融交替。控制变量是年均地温、含冰量、岩性、活动层厚度。青藏铁路冻土段
风沙与黄土第十章　风成地貌和黄土风的吹扬、搬运与堆积。控制变量是风速、起沙条件、物源、植被覆盖。洛川黄土剖面、巴丹吉林沙漠沙山
海岸与河口第十一章　海岸地貌及其堆积物波浪、潮流与河流共同作用。控制变量是波浪能、潮差、来沙量。黄河三角洲
湖泊与沼泽第十二章　湖泊、沼泽及其堆积物静水环境沉积与有机质积累。控制变量是水位、物源、温度（分解速率）。若尔盖泥炭沼泽
构造与新构造第十三、十四章内力给出舞台。控制变量是构造运动的方向与速率、岩性构造格局。汾渭地堑与西安地裂缝
第四纪地层与事件第十五、十六章时间与气候。控制变量是轨道尺度气候旋回、区域构造、沉积保存条件。泥河湾盆地、五大连池火山群
